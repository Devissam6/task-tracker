# Task Tracker CLI
(This document is LLM-generated)

A simple command-line tool to track your tasks and manage your to-do list. Tasks are stored locally in a JSON file.

## Features

- Add, update, and delete tasks
- Mark tasks as "in progress" or "done"
- List all tasks or filter by status
- Persistent storage in `tasks.json`
- Timestamps for creation and updates

## Installation

1. **Clone or download the script** to your local machine

2. **Make it executable** (optional, for convenience):
   ```bash
   chmod +x task-tracker.py
   ```

3. **Create an alias** (optional, to run as `task-tracker`):
   ```bash
   # Add to ~/.bashrc or ~/.zshrc
   alias task-tracker='python3 /path/to/task-tracker.py'
   ```
   Then reload your shell:
   ```bash
   source ~/.bashrc
   ```

## Requirements

- Python 3.6 or higher
- No external dependencies (uses only standard library)

## Usage

### Adding a Task

```bash
task-tracker add "Buy groceries"
# Output: Added task: Buy groceries
```

New tasks are automatically assigned a unique ID and marked as "todo".

### Updating a Task

```bash
task-tracker update 1 "Buy groceries and cook dinner"
# Output: Updated task: [1] [Buy groceries] -> [Buy groceries and cook dinner]
```

### Deleting a Task

```bash
task-tracker delete 1
# Output: Deleted task: [1] [Buy groceries and cook dinner]
```

### Marking Task Status

**Mark as done:**
```bash
task-tracker mark-done 1
# Output: Marked done: [1] [Buy groceries]
```

**Mark as in progress:**
```bash
task-tracker mark-in-progress 2
# Output: Marked in progress: [2] [Write report]
```

### Listing Tasks

**List all tasks:**
```bash
task-tracker list
```

**List by status:**
```bash
# List completed tasks
task-tracker list done

# List tasks in progress
task-tracker list prog

# List tasks not yet started
task-tracker list todo
```

## Task Properties

Each task in the JSON file contains:

| Field | Type | Description |
|-------|------|-------------|
| `id` | integer | Unique identifier (auto-incremented) |
| `description` | string | Task description |
| `status` | string | `todo`, `prog`, or `done` |
| `createdAt` | string | ISO 8601 timestamp of creation |
| `updatedAt` | string | ISO 8601 timestamp of last modification |

## Error Handling

The application handles these edge cases gracefully:

- **Missing JSON file**: Automatically creates an empty task list
- **Corrupted JSON file**: Overwrites with empty list on next run
- **Invalid task ID**: Displays appropriate error message
- **Missing arguments**: Argparse provides usage help

## Design Decisions

- **Flat script structure**: Chose a single-file implementation for simplicity while maintaining clear section separation
- **Sequential IDs with gap handling**: IDs are generated by finding the maximum existing ID + 1, preventing duplicates even after deletions
- **ISO timestamps**: Using standard format for cross-platform compatibility
- **JSON storage**: Human-readable format that can be manually edited if needed
- **No external dependencies**: Uses only Python standard library for maximum portability

- Local storage only (no cloud sync)
- Task descriptions must be quoted if they contain spaces
